# Обеспечение доверия (ГОСТ Р 59276—2020)

## 1. Меры доверия по стадиям ЖЦ

| Стадия ЖЦ | Мера | Реализация |
|---|---|---|
| Планирование | Прозрачные границы применимости | `docs/scope.md` |
| Проектирование | Архитектура и модель данных | `docs/architecture.md` |
| Подготовка данных | Очистка и provenance | `docs/provenance.md` |
| Индексация | Версия корпуса | `CORPUS_VERSION` |
| Верификация | Gold set и judge | `eval/report.json` |
| Эксплуатация | Квоты, логи, мониторинг | `app/guard`, `bot` |
| Вывод из эксплуатации | Архив отчётов и индексов | `reports/` |

## 2. Прозрачность и объяснимость

- Каждый ответ содержит цитаты: ГОСТ, пункт, страница.
- Цитаты проверяются по корпусу; неподтверждённые помечаются.
- При отсутствии ответа система отказывается и указывает пробел.
- Модель и провайдер фиксируются в ответе.

## 3. Управляемость

- Пользователь может задать уточняющий вопрос.
- Админ может переиндексировать корпус.
- Квоты и лимиты ограничивают нагрузку.

## 4. Ограничения доверия

- Ответы справочные, не являются официальным толкованием.
- LLM может ошибаться; цитаты снижают, но не исключают риск.
- Judge оценивает качество, но не заменяет эксперта.
