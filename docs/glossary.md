# Глоссарий (ГОСТ Р 71476—2024)

| Термин | Определение | Источник |
|---|---|---|
| Извлечение информации (information retrieval, IR) | Задача извлечения из набора данных релевантных материалов или их частей, обычно на основе запросов по ключевым словам или запросов на естественном языке | ГОСТ Р 71476—2024, п. 3.6.4 |
| Система искусственного интеллекта (система ИИ) | Техническая система, использующая ИИ для решения задач | ГОСТ Р 71476—2024, п. 3.1.4 |
| Знания | Структурированное содержание, сохраняемое системой по итогам наблюдений | ГОСТ Р 71476—2024, п. 5.4 |
| Граф знаний (knowledge graph) | Графическое представление структурированных знаний о понятиях и отношениях между ними | ГОСТ Р 71540—2024, п. 3.7 |
| Онтология (ontology) | Совокупность терминов, выражений отношений и связанных с ними определений | ГОСТ Р 71540—2024, п. 3.19 |
| База знаний | Хранилище знаний, построенное на онтологиях и графах знаний | ГОСТ Р 71540—2024, п. 8.3.4 |
| Жизненный цикл (life cycle) | Развитие системы от возникновения потребности до вывода из эксплуатации | ГОСТ Р 71476—2024, п. 3.11 |
| RAG (retrieval-augmented generation) | Паттерн, при котором генеративная модель получает найденные в базе знаний фрагменты как контекст | Внешний термин; в ГОСТах напрямую не определён |
| Чанк | Фрагмент документа, индексируемый как единица поиска | Внутренний термин проекта |
| Цитата | Ссылка на ГОСТ, пункт и страницу, подтверждающая утверждение | Внутренний термин проекта |
| Provenance | Информация о происхождении данных и цепочке преобразований | ПНСТ 847—2023 |
