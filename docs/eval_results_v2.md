# Результаты оценки v2

| Поле | Значение |
|---|---|
| Golden set | `eval/gold_set_v2.yaml` (37 вопросов, 12 типов) |
| Корпус | 38 документов, 4791 чанк: 3825 clause + 928 table + 38 meta (4643 уникальных по тексту) |
| Индекс | Qdrant `gost_chunks` + BM25, `multilingual-e5-large` (1024d) |
| Дата | 2026-11-12 |

## 1. Retrieval

| Метрика | Baseline v1 | Baseline v2 (первый прогон) | Финал v2.1 |
|---|---|---|---|
| Recall@8 | 1.000 (v1, 12 вопросов) | 0.722 (13/18) | **1.000 (18/18)** |

Первый baseline v2 измерялся при неработающем dense-поиске (см. п. 4), поэтому recall держался
только на exact-lookup и BM25. Финальный замер — после исправления `chunk_id`, multi-hop и
раскрытия перечислений, на переиндексированном корпусе (4791 чанк).

Что исправлено по ходу:

| Провал | Причина | Фикс |
|---|---|---|
| D01 компонент ИИ | короткое определение проигрывало BM25 | `ChunkStore.find_term()` — точный поиск по стемам заголовка пункта |
| D06 система ИИ | тот же + поиск без учёта ГОСТа | `find_term(term, gost)` с фильтром по документу |
| E02 этапы | parent expansion цеплялся за раздел 2 | для `enumeration` + ГОСТ — BM25 top-10 внутри документа |
| A01 приложение ДА | `APPENDIX_RE` захватывал 1 букву, `\b` не срабатывал; приложения из содержания отравляли `appendix` | regex `{1,2}`, проверка «(справочное)» в текущей/следующей строке, сброс `appendix` при смене раздела, чанк-заголовок приложения |
| P01 перефразировка | термин не обрезался по «в ГОСТ» | `TERM_RE` учитывает «по/в ГОСТ» |

## 3. Изменения относительно v1

| Изменение | Причина |
|---|---|
| MIN_CHARS 120 → 40 | короткие определения терялись |
| Чанки разделов | раздел 1 не попадал в индекс |
| Query classifier | разные типы вопросов требуют разных стратегий |
| Multi-hop retrieval | сравнения двух ГОСТов |
| Injection guard | отказ без вызова LLM |
| S3-ссылки с #page | переход к цитате в PDF |

## 4. Изменения v2.1

| Изменение | Причина |
|---|---|
| Dense-поиск снова работает (`chunk_id` из payload, а не UUID точки) | все dense-хиты отбрасывались в `Retriever` |
| Multi-hop: явный ГОСТ имеет приоритет + top_k 4 + область применения | сравнения теряли второй документ |
| Enumeration: раскрытие группы пунктов по BM25-свидетельствам | E02/E04 отдавали неполный список |
| Comparison с одним ГОСТом: разбиение на сущности | M05 не находил оба варианта использования |
| Extractive-ответ для clause_lookup | галлюцинации при верном контексте |
| Нормализация цитат («пункт 5.3.4, страница 19» → 5.3.4) | citation precision |
| meta-чанк на документ (дата введения, ISO-аналог) | temporal-вопросы |
| Table-чанки: pdfplumber + PyMuPDF fallback, 928 чанков | таблицы сплющивались в строку |
| Ответ «нет в источниках + общее знание (162-ФЗ)» | статус стандарта вне корпуса |
| Judge: citation = n/a для корректных отказов | метрика занижалась на 16 вопросах |
