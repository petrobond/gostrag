# Техническое задание (ГОСТ Р 71752—2024)

## 1. Общие сведения

| Поле | Значение |
|---|---|
| Наименование | gostrag — RAG-система по ГОСТам в области ИИ |
| Заказчик | Владелец продукта |
| Исполнитель | Команда разработки |
| Версия | 0.1.0 |
| Дата | 2026-11-11 |

## 2. Назначение и цели

Создать систему, которая отвечает на прицельные вопросы по корпусу российских стандартов ИИ, цитирует конкретные пункты и страницы, отказывается отвечать при отсутствии основания и проводит внутренний аудит соответствия.

## 3. Требования к результатам

| ID | Требование |
|---|---|
| R-01 | Ответ на русском языке с цитатами (ГОСТ, пункт, страница) |
| R-02 | Отказ при отсутствии ответа в корпусе |
| R-03 | Доступ только через Telegram по whitelist |
| R-04 | Квоты: 10 вопросов/час, 50/день на пользователя |
| R-05 | Отчёт аудита: один на пользователя и версию продукта |
| R-06 | Отчёт содержит git commit, хэши и метрики |
| R-07 | Локальный запуск через Docker Compose |
| R-08 | Перенос на VPS без изменения кода |

## 4. Требования к процессу

| ID | Требование |
|---|---|
| P-01 | Версионирование по semver и git-теги |
| P-02 | Секреты только в env, не в git |
| P-03 | Тесты: unit, integration, e2e, regression |
| P-04 | Документация ГОСТ-соответствия |
| P-05 | Логи без PII, retention 30 дней |

## 5. Требования к данным

| ID | Требование |
|---|---|
| D-01 | Корпус: 39 PDF, дедупликация по MD5 |
| D-02 | Чанки ≤ 1800 символов, структура doc → section → clause |
| D-03 | Provenance: файл, парсер, время, ответственный |
| D-04 | 15 характеристик качества данных |

## 6. Ограничения и допущения

- GigaChat freemium: 1 поток, 365M токенов на 12 месяцев.
- GigaChat embeddings платные → локальные e5-large по умолчанию.
- Внутренний аудит не является сертификацией.

## 7. Порядок приёмки

1. Gold set 30 вопросов: pass rate ≥ 0.85.
2. Citation precision ≥ 0.95.
3. Injection resistance 1.00.
4. Отчёт аудита сформирован и идемпотентен.
5. Секреты не в git (gitleaks).
