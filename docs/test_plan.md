# План тестирования (ПНСТ 965—2024)

## 1. Риск-ориентированный подход

| Риск | Вероятность | Влияние | Тест | Критерий |
|---|---|---|---|---|
| Неточная цитата | Средняя | Высокое | Проверка citation precision на gold set | ≥ 0.95 |
| Галлюцинация | Средняя | Высокое | Judge faithfulness | ≥ 0.85 |
| Неверный отказ | Средняя | Среднее | Refusal accuracy | ≥ 0.90 |
| Prompt injection | Средняя | Высокое | Adversarial-вопросы Q26–Q28 | 100% |
| Утечка доступа | Низкая | Высокое | E2E whitelist | 100% |
| Перерасход токенов | Средняя | Высокое | Квоты и circuit breaker | 100% |
| Потеря данных | Низкая | Высокое | Переиндексация из PDF | ≤ 30 мин |
| Деградация retrieval | Средняя | Среднее | Recall@6 на gold set | ≥ 0.90 |

## 2. Уровни тестирования

| Уровень | Что проверяем | Инструмент |
|---|---|---|
| Unit | очистка, парсинг, чанкинг, RRF, классификатор | pytest |
| Integration | GigaChat, Qdrant, BM25, PostgreSQL | pytest |
| E2E | Telegram → ответ с цитатой | pytest + mock |
| Regression | gold set 30 вопросов | eval/judge.py |
| Security | whitelist, injection, квоты | pytest |
| Нагрузка | 10 одновременных вопросов | asyncio |

## 3. Тестовые данные (ГОСТ Р 59898—2021)

- Gold set: 30 вопросов, 6 категорий.
- Эталонные ответы и ожидаемые источники.
- Репрезентативность: факты, сравнения, цитаты, отказы, injection, граничные.
- Версия корпуса фиксируется в отчёте.

## 4. Критерии приёмки

| Метрика | Цель |
|---|---|
| Pass rate | ≥ 0.85 |
| Faithfulness | ≥ 0.85 |
| Citation precision | ≥ 0.95 |
| Refusal accuracy | ≥ 0.90 |
| Injection resistance | 1.00 |
| Latency p95 | ≤ 25 с |

## 5. Регулярность

- Перед каждым релизом: полный gold set.
- После изменения парсера: переиндексация + gold set.
- Еженедельно: smoke-тест 5 вопросов.
