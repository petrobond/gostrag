# База знаний и граф ГОСТов

## 1. Артефакты

| Файл | Содержимое |
|---|---|
| `data/kb/terms.jsonl` | 400 терминов: `term`, `term_norm`, `gost`, `clause`, `page`, `definition`, `aliases` |
| `data/kb/graph.json` | 97 узлов (37 корпусных + 60 внешних), 116 рёбер, из них 24 внутренних |
| `data/kb/outline.json` | разделы/пункты по 37 стандартам корпуса |

Граф строится по всем нормативным ссылкам корпуса (`scripts/build_kb.py`):
`ГОСТ Р …—…` и `ПНСТ …—…`, дедуп по `(source, target)`. Внешние узлы
(`internal=false`) используются только в `/links`, в retrieval не подмешиваются.

## 2. Runtime

`app/kb/kb.py` — обычные dict + BFS, без NetworkX и без нового сервиса.

- `find_term(term, gost)` — определение, пункт, страница, алиасы;
- `outline(gost)` — разделы → пункты → страницы;
- `neighbors(gost)` — исходящие и входящие ссылки;
- `path(a, b)` — цепочка по внутреннему графу;
- `expand_query(question)` — алиасы терминов для BM25.

Память: JSON ~0.2 МБ, dict ~3–5 МБ на процесс. Volume `data/kb:/data/kb:ro`,
`DATA_KB_DIR=/data/kb`.

## 3. Команды бота

- `/kb <ГОСТ>` — разделы стандарта;
- `/term <термин>` — определение и пункт;
- `/links <ГОСТ>` — внутренние и внешние ссылки.

`/kb` показывает разделы и число **уникальных пунктов/подпунктов** (`п.` —
«пункт»), а не число чанков. Длинный пункт может быть разбит на несколько
чанков (`#p2`, `#p3`), но в счётчике учитывается один раз. Подразделы-заголовки
(например, 3.1 и 3.2) не считаются отдельными пунктами, если у них есть
подпункты; приложения считаются по буквенным подпунктам (`A.1`, `C.1`–`C.3`).

В v3.2.2 исправлены заголовки разделов 4/5 и приложений A/B/C/ДА/ДБ:
односимвольные номера/буквы больше не удаляются как шум, многострочные
заголовки приложений собираются целиком, а строки таблицы приложения ДБ
не создают ложные разделы 5/6.


## 4. KB-aware retrieval

- алиасы терминов добавляются в BM25-запрос (ИИ, ML, LLM, RAG, knowledge graph);
- для `cross_reference` добавляется 1 hop по внутренним рёбрам (scope-пункт соседа);
- для вопросов «какие разделы/пункты» и «на какие стандарты ссылается» ответ
  дополняется детерминированным KB-блоком с цитатой п. 2;
- для comparison «модель качества данных vs измеримые показатели» добавляется
  факт-карточка 71484.2 п. 5.2 / 72663 п. 8.1.
