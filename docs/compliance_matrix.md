## Легенда

- **Реализовано** — есть код/документ и проверка.
- **Частично** — есть реализация, но метрики будут заполнены после прогона judge.
- **Обосновано** — стандарт неприменим, причина зафиксирована.

## Ограничения

- Аудит внутренний, не сертификация.
- LLM-as-a-judge не заменяет эксперта.
- ГОСТы добровольного применения (ст. 26 162-ФЗ).
