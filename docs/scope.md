# Область применения и границы

| Поле | Значение |
|---|---|
| Продукт | gostrag |
| Версия | 0.1.0 |
| Дата | 2026-11-11 |

## 1. Назначение

RAG-система для ответов на прицельные вопросы по корпусу российских стандартов в области ИИ (ГОСТ Р и ПНСТ). Ответы содержат цитаты: номер стандарта, пункт, страницу.

## 2. Классификация системы (ГОСТ Р 59277—2020)

| Признак | Значение | Обоснование |
|---|---|---|
| Характер задач | Информационно-поисковая и вопросно-ответная | Основная функция — поиск и ответ |
| Тип данных | Текст | Русскоязычные PDF |
| Автономность | Автономная с человеком в контуре | Решения справочные, требует проверки |
| Обучение | Не обучается | Использует внешние модели и базу знаний |
| Архитектура | RAG | Retrieval + генеративная модель |
| Уровень риска | Ограниченный | Не является официальным заключением |
| Область применения | Внутренняя экспертиза стандартов | Не КИИ |

## 4. Не применимые стандарты

| Стандарт | Причина |
|---|---|
| ПНСТ 1046—2026 (ИИ в КИИ) | Система не входит в критическую информационную инфраструктуру и не предназначена для применения в её составе |
| ПНСТ 836—2023 (функциональная безопасность) | Система не управляет объектами повышенной опасности; отказ системы приводит только к недоступности справочной функции |
| ГОСТ Р 71562—2024 (метрологическое обеспечение) | Средства измерений на основе ИИ не разрабатываются и не применяются |

## 5. Ограничения

- Аудит внутренний, не является сертификацией.
- ГОСТы добровольного применения (ст. 26 162-ФЗ «О стандартизации»).
- LLM-as-a-judge не заменяет эксперта.
- Ответы не являются официальным толкованием стандартов.
