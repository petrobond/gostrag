# Архитектура и контекст применения

## 1. Контекст применения (ПНСТ 963—2024)

| Аспект | Значение |
|---|---|
| Назначение | Справочная экспертиза российских стандартов по ИИ |
| Пользователи | Владелец продукта, приглашённые эксперты |
| Среда | Локальный Docker Compose, затем VPS в РФ |
| Ограничения | Только Telegram, whitelist; русский язык; корпус фиксирован |
| Внешние системы | GigaChat API (LLM, embeddings при оплате), DeepSeek (fallback) |

Заинтересованные стороны: владелец продукта (админ), эксперты, разработчик, аудитор.

## 2. Слои архитектуры (ГОСТ Р 71540—2024)

| Слой | Реализация | Артефакты |
|---|---|---|
| Источники | 39 PDF в `data/source` | `data/corpus/documents.json` |
| Конструирование знаний | `app/ingest`: extract → clean → parse → chunk | `data/corpus/chunks.jsonl`, `quality_report.json` |
| Платформа знаний | Qdrant (векторы), BM25 (разреженный индекс), PostgreSQL (метаданные) | `data/index/*` |
| Применение | FastAPI, Telegram-бот, retriever, generator | `app/`, `bot/` |
| Управление качеством | Judge, gold set, отчёты | `eval/`, `docs/` |

## 3. Жизненный цикл (ГОСТ Р 71476—2024, раздел 6)

| Стадия ЖЦ | Действия проекта |
|---|---|
| Планирование | ТЗ, план, классификация системы |
| Проектирование | Архитектура, модель данных, промпты |
| Сбор данных | Комплектование корпуса, дедупликация |
| Подготовка данных | Очистка, парсинг, чанкинг, метаданные |
| Обучение/индексация | Построение эмбеддингов и индексов |
| Верификация | Gold set, judge, тесты |
| Развёртывание | Docker Compose, затем VPS |
| Эксплуатация | Мониторинг, квоты, обновление корпуса |
| Вывод из эксплуатации | Архивирование индексов и отчётов |

## 4. Компоненты

```
bot (aiogram) → app (FastAPI) → guard → retriever → generator → GigaChat/DeepSeek
                                   │           │
                                   ▼           ▼
                              PostgreSQL    Qdrant + BM25
```

## 5. Поток ответа

1. Whitelist и rate limit.
2. Нормализация вопроса и классификация сложности.
3. Dense top-20 + BM25 top-20 → RRF → top-6.
4. Промпт с цитатами и защитой от injection.
5. GigaChat Ultra → Max → Pro → Lite → DeepSeek.
6. Валидация цитат по корпусу.
7. Ответ с источниками.

## 6. Ограничения архитектуры

- GigaChat freemium: 1 одновременный поток → очередь.
- GigaChat embeddings требуют оплаты → локальные e5-large (1024 dim) по умолчанию.
- Генерация и эмбеддинги — разные провайдеры; при смене эмбеддера требуется переиндексация.
