# Качество данных (ГОСТ Р 71484.2/.3/.4—2024, ГОСТ Р 72663—2026)

## 1. Пятнадцать характеристик качества данных

| № | Характеристика | Как проверяем в проекте | Целевое значение |
|---|---|---|---|
| 1 | Аккуратность | Сверка цитат с исходным PDF | ≥ 0.95 |
| 2 | Наполненность | Доля пунктов с текстом | ≥ 0.90 |
| 3 | Согласованность | Дубликаты по text_hash | ≤ 5% |
| 4 | Достоверность | Отсутствие битых строк и обрывков | ≥ 0.98 |
| 5 | Актуальность | Дата версии корпуса, статус стандарта | 100% |
| 6 | Доступность | Все чанки в Qdrant и BM25 | 100% |
| 7 | Соответствие | Формат JSONL, обязательные поля | 100% |
| 8 | Конфиденциальность | Нет PII в корпусе и логах | 100% |
| 9 | Эффективность | Время индексации и поиска | p95 ≤ 25 с |
| 10 | Точность | Соответствие пункта и страницы | ≥ 0.95 |
| 11 | Прослеживаемость | provenance до файла и пункта | 100% |
| 12 | Понятность | Читаемость текста после очистки | ≥ 0.95 |
| 13 | Готовность | Индекс доступен и отвечает | 100% |
| 14 | Переносимость | Docker Compose, относительные пути | 100% |
| 15 | Восстанавливаемость | Переиндексация из PDF | ≤ 30 мин |

## 2. Показатели (ГОСТ Р 72663—2026)

Для каждой характеристики фиксируются измеримые показатели в `data/corpus/quality_report.json`:

- количество документов, пунктов, чанков;
- минимальная, максимальная и средняя длина чанка;
- число дубликатов по хэшу;
- документы без чанков;
- распределение чанков по документам.

## 3. Процесс управления качеством (ГОСТ Р 71484.4—2024)

| Этап | Действие | Артефакт |
|---|---|---|
| Планирование | Определить требования и показатели | `docs/data_quality.md` |
| Оценка | Профилирование корпуса | `quality_report.json` |
| Повышение | Удаление дубликатов, исправление парсинга | `corpus_change_log.jsonl` |
| Валидация | Повторная оценка | `quality_report.json` (v2) |

## 4. Жизненный цикл данных

| Шаг | Реализация |
|---|---|
| Формирование требований | Список 39 документов, версии |
| Планирование | Ответственный: corpus-admin |
| Комплектование | Дедупликация по MD5 |
| Подготовка | Очистка, парсинг, чанкинг |
| Предоставление | Qdrant + BM25 |
| Вывод из эксплуатации | Архивирование версии корпуса |
