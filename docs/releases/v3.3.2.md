## Что исправлено

В v3.3.1 обработчик Enter навешивался на textarea при загрузке страницы.
После первого ответа HTMX заменяет `#thread-inner`, создаёт новый composer,
и обработчик терялся — Enter переставал отправлять вопрос.

Теперь используется делегирование:

```js
document.addEventListener("keydown", (event) => {
  const textarea = event.target.closest?.("textarea[data-enter-submit]");
  ...
});
```

Поведение:

- **Enter** отправляет вопрос, в том числе после HTMX-свопа;
- **Shift+Enter** — перенос строки;
- IME-ввод не отправляет форму;
- повторная отправка блокируется, пока кнопка disabled;
- fallback-форма без HTMX работает через `requestSubmit()`.

RAG, промпты, данные и БД не менялись. Переиндексация не нужна.

отправляется; Shift+Enter добавляет строку.
