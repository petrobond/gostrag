## Изменения

- `bot/commands.py` — публичное и расширенное (админское/whitelist) меню.
- `bot/main.py` — `set_my_commands` при старте:
  - глобально: `/start`, `/help`, `/gosts`, `/ask`, `/kb`, `/term`, `/links`;
  - для whitelist/админов: дополнительно `/stats`, `/audit`, `/audit_status`.
- Ошибка настройки меню не останавливает polling.
- Тесты: проверка состава и формата `BotCommand`.
