# Release v3.2.4

## Итог

Бот открыт для всех пользователей Telegram. Административные функции
(`/stats`, `/audit`, `/audit_status`) доступны только владельцу.

| Параметр | Значение |

| Тег | `v3.2.4` |
| Версия продукта | `3.2.4` |
| Версия корпуса | `2026.11.13-r2` |
| Ветка | `release/v3.0.0` |

## Изменения

- `handle_question` больше не проверяет `TELEGRAM_USER_IDS`: вопросы может
  задавать любой пользователь.
- `/audit` и `/audit_status` проверяют только `TELEGRAM_ADMIN_IDS`.
- `/stats` уже был admin-only.
- Меню: публичные команды — всем; `/stats`, `/audit`, `/audit_status` —
  только чату администратора.
- Сохранены per-user лимиты: 10 вопросов/час и 50/день по умолчанию.
- `TELEGRAM_USER_IDS` остаётся в конфиге для обратной совместимости, но
  больше не ограничивает доступ.
