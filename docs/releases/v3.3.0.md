## Что добавлено

- Лёгкий веб-интерфейс на FastAPI + Jinja2 + htmx: вход, чат по ГОСТам,
  ответы с цитатами (ГОСТ, пункт, страница, PDF `#page=N`), история диалогов.
- Авторизация email + пароль только по приглашению; Argon2id, серверные
  cookie-сессии (`__Host-`, HttpOnly, Secure, SameSite=Lax), CSRF, throttle входа.
- Роли `user` / `admin`; `admin` назначается только через CLI.
- Админка: статистика, пользователи/приглашения/блокировка/сброс пароля,
  документы корпуса и отчёты аудита (read-only).
- Reverse proxy Caddy с автоматическим TLS (профиль `proxy`), HSTS, CSP,
  блокировкой `/api/ask` и `/health` снаружи.
- Миграции `web_*` в PostgreSQL, CLI `web-user` и `db migrate`.
- CI: PostgreSQL-сервис для интеграционных тестов веб-таблиц.

## Что не менялось

- `/api/ask`, Telegram-бот, Qdrant, корпус, аудит и eval.
- `qa_log` / `usage_daily` не смешиваются с веб-сессиями.

## Проверка

```bash
.venv/bin/python -m pytest -q tests          # 131 passed, 5 skipped
.venv/bin/python -m ruff check app bot eval tests
make dev-up && make api
bash scripts/smoke_web.sh http://127.0.0.1:8000
```

Проверено вручную (локальный контур, PostgreSQL 16):
гость → редирект на `/login`, вход админа, `/chat`, `/admin`, `/admin/users`,
`/admin/documents`, `/admin/audit`, `/api/web/admin/stats`.

## Деплой

1. В `deploy/.env` добавить `WEB_DOMAIN` и `WEB_*` (см. `deploy/.env.example`),
   открыть TCP 80/443 на VPS.
2. Собрать и задеплоить тег `v3.3.0` (CI/CD).
3. Создать администратора и открыть одноразовую ссылку:

```bash
sudo docker compose -f deploy/docker-compose.yml --env-file deploy/.env \
  run --rm app python -m app.cli web-user create \
  --email bondarev-petr@yandex.ru --role admin
```

4. Проверить `https://<WEB_DOMAIN>/login`, `/health` (`web_ready: true`),
   `/api/ask` снаружи → 404.

## Откат

Откат образа на `v3.2.4` оставляет веб-таблицы в БД (они не используются старой
версией). Бот и `/api/ask` продолжают работать. Веб-интерфейс пропадает.
