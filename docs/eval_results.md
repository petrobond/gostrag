## 3. Известные ограничения

| Вопрос | Проблема | Причина |
|---|---|---|
| Q05 | Неверный перечень этапов | Retrieval вернул 6.1/7.2/6.5 вместо 6.2–6.5 |
| Q06 | Лишние слои в ответе | В стандарте есть инфраструктура и многослойные функции; эталон обновлён |
| Q11, Q12, Q15 | Сравнения | Модель не всегда сводит два стандарта в один ответ |
| Q18, Q20 | Точные цитаты | Возможны неточные page/quote |
| Q29 | Умный дом | Документы без нумерованных пунктов не проиндексированы |

## 4. Ограничения методики

- Judge — LLM, возможна предвзятость и строгость к формулировкам.
- Gold set из 30 вопросов не покрывает весь корпус.
- Оценка проводилась на одном прогоне (temperature 0.1).
- Внутренний аудит не является сертификацией.
