## Причины

### Короткий ГОСТ

`GOST_RE` требует год. `ГОСТ Р 71476` не попадал в `extract_gosts`, поэтому
Qdrant/BM25 работали без фильтра и 71476 не попадал в top-k. С полным номером
фильтр включает 71476, `find_term` находит п. 3.2.2 «проверка качества данных».

### Неполный список

Вопрос классифицировался как `enumeration`, LLM получал только top-k чанков
и перечислял стандарты из контекста (10 из 37). В корпусе 38 документов,
37 уникальных стандартов (19 ГОСТ Р + 18 ПНСТ).

## Реализация

1. `app/rag/gost_refs.py`: regex с необязательным годом, alias-map по каноническим
   номерам, резолвер; неоднозначные/неизвестные номера не трогаются.
2. `Retriever`: alias-map из `chunks.by_gost`, `resolve_query()`, вызов в
   `retrieve()`/`retrieve_comparison()`; `AskService` резолвит вопрос один раз
   и использует его во всех стадиях, сохраняя оригинал для логов.
3. `app/rag/corpus_catalog.py`: группировка манифеста, русские плюрали, полный
   список, `build_meta_citations()`.
4. `query_classifier`: строгий `corpus_list` (gold v2/v3/kb — 0 срабатываний).
5. `AskService._corpus_list_answer()`: детерминированный ответ, 37 мета-цитат,
   `model=deterministic:corpus_list`, `provider=rules`, без LLM.
6. Веб: `data-enter-submit` + `requestSubmit` в `app.js`; Shift+Enter — перенос.
7. Мета-цитаты в боте/вебе отображаются как `ГОСТ, с. 1` без «п. meta».
