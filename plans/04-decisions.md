# Журнал архитектурных решений (ADR)

## ADR-001. GigaChat 3 Ultra как primary LLM

- **Статус:** принято.
- **Контекст:** нужна дешёвая русскоязычная модель; у физлица доступен freemium 50M токенов на Ultra.
- **Решение:** primary — `GigaChat-3-Ultra`; fallback — Max → Pro → Lite → DeepSeek.
- **Последствия:** 1 одновременный поток → очередь; после исчерпания freemium — платные модели.

## ADR-002. Локальные эмбеддинги вместо GigaChat embeddings

- **Статус:** принято (вынужденно).
- **Контекст:** GigaChat embeddings возвращают HTTP 402 (не входят в freemium).
- **Решение:** по умолчанию `intfloat/multilingual-e5-large` через FastEmbed (ONNX, 1024 dim, контекст 512).
- **Последствия:** чанки ≤ 1800 символов; при переходе на GigaChat embeddings (2048 dim) требуется переиндексация.
- **Альтернатива:** оплатить пакет GigaChat embeddings (700 ₽ за 50M токенов).

## ADR-003. Qdrant как векторное хранилище

- **Статус:** принято.
- **Контекст:** нужен быстрый ANN с фильтрами по ГОСТу.
- **Решение:** Qdrant в Docker, коллекция `gost_chunks`, 1024 dim, cosine.
- **Последствия:** ещё один сервис; при минимальном стеке можно заменить на pgvector.

## ADR-004. Гибридный поиск BM25 + dense + RRF

- **Статус:** принято.
- **Контекст:** русские ГОСТы содержат точные номера, термины и формулировки.
- **Решение:** BM25 с pymorphy3 + dense e5 + Reciprocal Rank Fusion.
- **Последствия:** BM25-индекс в памяти (~30 МБ), строится при индексации.

## ADR-005. Структурный чанкинг по пунктам

- **Статус:** принято.
- **Контекст:** вопросы прицельные, нужна точная цитата (ГОСТ, пункт, страница).
- **Решение:** чанк = пункт (`N.N.N`), max 1800 символов, parent — раздел.
- **Последствия:** 2395 чанков; терминологические документы без нумерации не индексируются (2 документа).

## ADR-006. Версионирование отчётов аудита

- **Статус:** принято.
- **Контекст:** требование «один отчёт на пользователя для конкретной версии продукта».
- **Решение:** путь `reports/{version}/{user_id}/`, manifest с git commit, tag и SHA-256; при наличии manifest отчёт не перегенерируется.
- **Последствия:** идемпотентность; при изменении версии создаётся новый отчёт.

## ADR-007. Доступ только через Telegram

- **Статус:** принято.
- **Контекст:** минимизация поверхности атаки и затрат.
- **Решение:** whitelist по `user_id`, rate limit 10/час и 50/день, антифлуд.
- **Последствия:** нет публичного web-доступа; для демонстрации используется Telegram.
